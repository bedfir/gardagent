## 3. Differences between the documentation and reality (fixed in this branch)

1. The harness needs the key of a long-lived `pilot-zero` agent in `$PZ_KEY_FILE`; nothing explained how to create it on a fresh
   `deploy/` install, nor the production-like variables (they were only in a script header). Added to `docs/pilot-zero.md`.
2. The failed-authentication limit cannot be tested from outside: Caddy answers 403 before the gateway sees the request, so nothing
   is counted. `docs/self-hosting.md` now says to test from an allowed address.
3. No documented way to read the running version. `docs/self-hosting.md` now shows one.
4. The host prerequisite said "a clone of this repository" while a private or offline host needs an archive. Reworded.

## 4. Limits

* Anthropic-format endpoint (`/v1/messages`) against the real Anthropic API was not exercised in this run.
* The 29 "other HTTP errors" of criterion (g) were not broken down in this run (earlier rounds attributed them to 503 answers during
  the restarts).

The 29 unclassified errors from this run cannot be reconstructed; the harness now classifies restart failures by transport cause, HTTP status, and gateway error code.
