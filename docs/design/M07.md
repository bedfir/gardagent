# M07: Standalone verifier

## Problem
A recipient needs to verify an M06 export without a database, gateway installation or network access, including comparison with independently retained checkpoints.

## Decision
Create a dependency-free Node.js package and CLI. Independently implement canonical JSON, SHA-256 chaining, format constraints and approval correlation from ledger-format.md. This avoids sharing an implementation defect with the writer; golden fixtures and real M06 exports test interoperability. No runtime dependency on core or gateway. Tests may use both as independent producers.

Accept M06 NDJSON pages concatenated in order. Require genesis, consecutive entries, consistent captured heads across metadata records, page cursors matching their page, and a complete export reaching the captured head. Metadata timestamps may differ across pages. External checkpoints are separately supplied JSON files. Every supplied checkpoint must be structurally valid and contained at its exact sequence. An embedded head is not an independently trusted checkpoint.

Return machine-readable results with entry count, verified prefix head, first failing entry and reason, per-checkpoint containment, and a statement of the truncation limitation. Malformed input and incomplete exports fail closed. CLI exit status is zero only for an entirely valid result. Read files in memory for this first version; document the memory limitation.

## Alternatives rejected
Importing core verification would reuse the writer's hash implementation and would not test the written specification independently. Accepting partial exports would make a missing prefix or incomplete download look like a successful full verification. Authenticating checkpoints cryptographically is outside M07: recipients must establish checkpoint provenance separately.

## Compatibility
No stored rows or existing APIs change. Both unmarked version 1 and version 2 entries verify, including mixed chains with a version 1 prefix. Absent fields remain absent from the hash. No dependencies or lockfile changes are needed.
