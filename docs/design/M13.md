# M13 — Release chain

## Problem

Release tags publish an unsigned image with no dependency inventory or build evidence. Users cannot bind a pulled image to this repository's release workflow.

## Decision

Keep the existing single-platform GHCR build and tags. Pin every action to a full commit hash. BuildKit attaches SPDX SBOM and maximal SLSA provenance attestations to the published OCI index. Cosign signs that index by immutable digest using GitHub OIDC and the public Sigstore transparency log. A signature over the index binds the platform manifest and the attestation manifests through their content digests. Do not describe these as separately signed Cosign attestations.

Give only the image job contents read, packages write and id-token write permissions; disable checkout credential persistence. Verification first authenticates the index against an exact workflow/tag identity, then uses Buildx to extract its attached attestations. Require inspection of source, revision, subject and inventory rather than interpreting successful extraction as trust.

Delegate the required Unreleased sentence to OpenCode via the runner because CHANGELOG.md is outside the implementation scope. No dependencies are added to the application.

## Alternatives rejected

Long-lived signing keys require secret management. Separate inventory uploads would not automatically bind inventory to the signed index. A second provenance publisher would introduce another attestation format and verification path without improving this mission's minimal chain.

## Compatibility impact and limits

Existing version and latest tags stay available; the tag now addresses an index containing one runnable platform plus attestations. Consumers must support OCI indexes. Earlier images acquire no evidence retroactively. Floating base images, tooling, package resolution and build timestamps prevent any claim of bit-for-bit reproducibility. Local static review cannot validate GHCR, OIDC, transparency-log access or registry attestation retention; a human must push the first tag and complete the documented checks.
